# Glossary

Shared vocabulary. One entry per term, alphabetical. Keep definitions
to two or three lines: this is a shared reference, not a tutorial.

Rules:

- If a term appears in the subject, use the subject's word for it, not
  a synonym you prefer.
- If two of us use different words for the same thing, one of them
  wins here and the other disappears from the code.
- Term names used as identifiers in the code go in `code:` so the
  mapping between vocabulary and source is explicit.

---

## Format

### <Term>

Definition in two or three lines. What it is, and the one distinction
people usually get wrong about it.

- **Not to be confused with:** <nearby term>
- **code:** `IdentifierUsedInSource`
- **See:** RFC section or man page, if there is a canonical source.
